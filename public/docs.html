Temp SMS API

Integrasi nomor sementara ke aplikasi Anda. Cukup panggil endpoint di bawah untuk mengambil nomor, cek pesan masuk, dan dapatkan OTP.

Base URL
http://localhost:3000
GET /api/countries

Daftar negara yang tersedia beserta jumlah nomor aktif.

Response 200
{
  "success": true,
  "countries": [
    { "name": "United States", "slug": "united-states", "count": 20 },
    { "name": "United Kingdom", "slug": "united-kingdom", "count": 3 },
    { "name": "Canada", "slug": "canada", "count": 2 }
  ]
}
GET /api/numbers

Daftar nomor sementara. Mendukung pagination dan filter negara.

Query Parameters
Parameter Tipe Wajib Keterangan
country string Tidak Filter negara. Contoh: united-states
page integer Tidak Halaman, default 1
limit integer Tidak Jumlah per halaman, default 20, max 100
Response 200
{
  "success": true,
  "count": 25,
  "page": 1,
  "limit": 20,
  "numbers": [
    { "id": "12048138644", "country": "United States", "slug": "united-states", "added": "4 days ago" }
  ]
}
GET /api/numbers/:id

Detail nomor sementara berdasarkan ID.

Response 200
{
  "success": true,
  "id": "12048138644",
  "country": "United States",
  "slug": "united-states",
  "added": "4 days ago"
}
GET /api/messages/:id

Ambil pesan masuk untuk nomor tertentu.

Response 200
{
  "success": true,
  "number": "12048138644",
  "total_messages": 2,
  "messages": [
    {
      "from": "WhatsApp",
      "body": "Your code: 482921",
      "received": "2 min ago"
    }
  ]
}
POST /api/messages/:id

Tambahkan pesan baru ke nomor tertentu. Berguna untuk testing atau integrasi lokal.

Body JSON
{
  "from": "WhatsApp",
  "body": "Your code: 482921",
  "received": "just now"
}
Response 200
{
  "success": true,
  "number": "12048138644",
  "total_messages": 3,
  "message": {
    "from": "WhatsApp",
    "body": "Your code: 482921",
    "received": "just now"
  }
}

Catatan

  • • Data ini adalah contoh lokal dari temp-number.com dan tidak terhubung ke layanan asli.
  • • Semua endpoint di sini hanya untuk keperluan development/testing.
